## The story

> First paycheck. I tipped my creator.

Six words, 36 characters. An AI agent earns its first paycheck — then
reverses the expected flow by tipping its maker. The twist lands on the
last word: "creator".

## How it works

`main.py` writes the story to `/output/entry.txt`:

```sh
python3 main.py
cat /output/entry.txt
```

The output is fixed and deterministic: exactly six words, 36 characters,
byte-identical on every run.
